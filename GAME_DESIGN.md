# Stonebalance: Game Design

**Pillars:** feels real, plays naturally, relaxes the mind, challenges the brain.

**Loop:** a piece hovers above the stack. Drag to position, tap Rotate to turn it, release to drop. Physics settles it, then the next piece appears.

**Modes:** Relax (infinite pieces, no goals), Classic (6 levels, fixed piece sequence per level, optional wind), Daily (same puzzle per date, no streaks).

**Progression:** pass a level by reaching its goal height; next level unlocks; personal bests saved. No energy, timers, streaks or forced logins.

**Pieces:** stone, wood, ceramic; box and disc shapes; mass from density x volume; friction per material.

**Accessibility:** goal shown as text and a marker line (not color only), reduced-motion camera, vibration toggle, mute, 3 graphics tiers, 150px touch targets.

**Monetization:** none now. Future: optional cosmetic sets, optional premium upgrade. Never interrupt play.
