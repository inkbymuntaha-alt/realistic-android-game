# Stonebalance

A relaxing, realistic 3D stone-stacking puzzle for Android, built with Godot 4.4 (Mobile renderer, Jolt physics).
Stack stones, ceramics and wood on a riverbank. Offline, no account, no ads, no timers.

## Run (desktop preview)
1. Install Godot 4.4.x.
2. Open this folder as a project and press Play. Mouse drag emulates touch.

## Test
`godot --headless --import` then `godot --headless --script tests/run_tests.gd`

## Status
Source only. No APK/AAB is produced and packaging is disabled until explicit approval. See ROADMAP.md and TESTING.md.
